Terminology: *row* = raw log line; *event* = distinct (user_id, video_id, time_ms); *pair* = distinct (user_id, video_id); *positive* = a row with label 1 for the action. *OOC* (out of catalog) = a test positive whose item is not in the candidate catalog under consideration, so no model ranking that catalog can retrieve it. Timezone Asia/Shanghai (CST), inferred from `date` agreement (99.17% of rows).

Split-dependent numbers (§6, §7, §9, §10) use a **provisional reference split** (`row_quantile_raw`, §5), for audit only. It is not a protocol decision: the formal evaluation uses CST-midnight cuts (`results/data_pipeline/DATA_REPORT.md`).
